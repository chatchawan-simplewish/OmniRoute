# Q4 R9 isolated qualification successor contract

Status: **SOURCE ONLY / NOT REVIEWED / NOT EXECUTABLE.** This is a new Q4 qualification gate, not a retry or authority claim for any historic invocation. It permits no SSH, Docker, credential, provider, traffic, state, gateway, or client-default action.

## Retained trust root

The independently reviewed package is the exact canonical v2 action plus the launcher, helper, contract, focused test, runtime program, runtime command, collector program, and one Q4 request. The source manifest and Sol High approval pin the SHA-256 of all eight byte strings and the canonical action. Direct CLI loading of the launcher is refused: the future exact-action executor must read the launcher once into a retained byte object, execute those bytes with `__file__="<retained-q4-r9-launcher>"` and `__retained_launcher_bytes__` set to that same object, and pass only the ten reviewed file/parent arguments. The retained launcher reads every remaining source, operational input, action, and approval once with regular-file, size, stable-inode/size/mtime and `O_NOFOLLOW` checks. It never reopens them. It executes the retained helper bytes directly from memory. The helper executes the retained runtime and collector bytes through a fixed Python `-I` stdin-pipe shim; command, request, action, and secret bytes also travel only through bounded stdin pipes. No reviewed or executed byte is later recovered from a pathname.

The action pins the secret-parent and secret-leaf device, inode, owner, mode, size, and mtime metadata obtained by a separate read-only descriptor preflight. At execution, the helper opens the caller-selected parent once with `O_DIRECTORY|O_NOFOLLOW`, opens the basename-only secret with `openat(..., O_NOFOLLOW)`, derives both identities with `fstat`, and requires exact equality before reservation. State and terminal leaves are created relative to that same held parent descriptor with `O_EXCL|O_NOFOLLOW`, mode `0600`, file fsync, and parent fsync. Thus caller paths select objects but cannot assert their identities or redirect leaf publication after the handles are opened. Execution is POSIX-only and refuses Windows because Windows Python lacks the required `openat` boundary.

## One future consuming action

Before reading the secret, the helper validates exact schemas and canonical bytes, rehashes every retained source/operational byte, validates the approval and operational pins, rejects unsafe/distinct-leaf failures, proves the opened credential identity, refuses any existing state or terminal leaf, and publishes the immutable `Q4_R9_UNKNOWN` / `gate_spent=true` state. It then reads the already-opened regular secret once with stable identity/size/mtime checks. The secret is never logged, hashed, emitted, written to a file, or placed in argv/environment.

The retained runtime program receives the retained canonical action and command once in `start` mode under the action timeout. Any timeout, nonzero exit, stdout, or stderr is failure/uncertain. After a successful start, the retained collector receives the retained action, exact Q4 request, and secret once under the action timeout. There is no retry, fallback, Q6 request, historic-gate reference, cleanup, or second collection. A single retained-runtime `stop` invocation is attempted in `finally`, including after lost/failed start acknowledgement; any timeout, nonzero exit, stdout, or stderr prevents PASS. UNKNOWN/SPENT remains authoritative for every failure or uncertainty.

PASS requires the collector's bounded stdout to be canonical JSON with no duplicate or extra keys and empty stderr. The exact evidence schema binds the approved runtime and contains: authenticated health HTTP 200 for the pinned candidate; authenticated models HTTP 200 containing the pinned Q4 model; and exactly one completion HTTP 200 bound to the pinned candidate, Q4 model, and connection, with integer request count one, a UUIDv4 request ID, and positive integer content bytes. Boolean integers, caller dictionaries, runtime self-attestation objects, noncanonical bytes, and unreviewed collectors are rejected. Only the evidence SHA-256 and safe request ID are retained in the exclusive PASS leaf after the reviewed stop program proves stopped retention.
